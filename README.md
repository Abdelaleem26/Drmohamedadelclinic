# عيادة د. محمد عادل مخلوف

موقع تعريفي للعيادة (باطنة وجهاز هضمي وأطفال، صهرجت الصغرى، أجا، الدقهلية). HTML و CSS و JavaScript عادي، من غير أي أدوات بناء.

## التشغيل
افتح `index.html` في المتصفح. الخطوط من Google Fonts فتحتاج إنترنت.

## التعديل
- الخدمات والشهادات في مصفوفتين `SERVICES` و `CERTS` أول السكريبت.
- رقم الواتساب في `WA_NUMBER`.
- الصور في `images/`. صور الشهادات في `images/certs/`.
- الألوان في `:root` أول ملف الـ CSS (أخضر الشعار الغامق، أحمر القلب للحجز، وخلفيات عاجية).

# Dr. Mohamed Adel Makhlouf Clinic

Single-page Arabic (RTL) site for an internal medicine, gastroenterology and pediatrics clinic in Aga, Dakahlia. Plain HTML, CSS and JavaScript, no build step. Open `index.html`; fonts load from Google Fonts. Services and certificates are data arrays at the top of the script, and the WhatsApp number is `WA_NUMBER`.
